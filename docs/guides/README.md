# Guides

One short guide per reader. Printables are generated by the app, so they always carry the shop's own name, QR code and current button names.

| Guide | For | Where |
|---|---|---|
| [Owner quick start](owner-quick-start.md) | Owner | Sign up → shop live in about 30 minutes, then the daily routine |
| **Staff guide** (one A4 page, BM / EN / 中文) | Staff | In the app: **Staff → Staff guide** → pick the language → Print |
| **Customer poster** (A4, BM / EN / 中文, with the shop's QR) | Customers | In the app: **Machines → Print customer poster**, or Shop settings → Poster |
| [Sensors: what to buy + home test](sensors-buy-and-home-test.md) | Owner | Optional: hardware list with rough prices, and a 30-minute test at home with a plug-in Shelly |
| [Electrician job sheet](sensors-electrician.md) | Registered electrician (+ owner before/after) | Fitting clamp sensors in the shop's distribution board |
